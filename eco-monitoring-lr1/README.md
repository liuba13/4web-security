# ЕкоМоніторинг — навчальний застосунок для ЛР 1

Веб-система моніторингу якості повітря: станції спостереження, API екологічних даних (вимірювання PM2.5, PM10, NO₂, CO), панель оператора. Застосунок реалізовано на Next.js (App Router) + TypeScript.

> ⚠️ Це навчальний додаток із навмисно закладеними вразливостями. Призначений ВИКЛЮЧНО для локального аудиту в межах лабораторної роботи.

## Вимоги

- Node.js 20+ (перевірка: `node -v`)
- npm

Docker **не потрібен**, бо застосунок використовує вбудоване файлове сховище (каталог `data/`).

## Запуск

```bash
npm install
npm run dev
```

Застосунок відкриється на `http://localhost:3000`.

Продакшн-режим (за потреби для сканування зібраної версії):

```bash
npm run build
npm start
```

## Структура

```
data/                     seed-дані (станції, вимірювання, користувачі)
src/
  middleware.ts           перевірка доступу до захищених маршрутів
  lib/                    доступ до даних, автентифікація, обробка помилок
  app/
    login/                сторінка входу
    dashboard/            панель екомоніторингу
    api/
      auth/login/         POST — вхід
      stations/           GET  — список станцій
      stations/[id]/      GET  — станція за id
      measurements/[id]/  GET  — вимірювання станції
      export/             GET  — експорт даних
```
